### 模板是"双轨"的

```
templates\
├─ 知识卡.md 等 7 个      ← 当前默认（原生版，不装插件就能用）
├─ 原生\                  ← 原生版原件
└─ Templater\             ← Templater 版原件（自动填标题、弹窗选领域）
```

切换：`node tools/setup-obsidian.mjs --templater`（或 `--native` 切回来）

> **为什么要双轨**：沙箱环境无法下载插件，所以先让原生版可用，保证"装了 Obsidian 就能记笔记"；
> 等 Templater 装好再切过去，不会因为插件没装而卡住。

### 必须手动做的：装三个社区插件

Agent 沙箱禁止出站 TLS（实测 `SEC_E_NO_CREDENTIALS`），**插件文件下载不了**，
且本机 v2rayN / clash 当前均未运行。所以这一步只能在 Obsidian 界面里做：

```
1. 打开 Obsidian → 设置（左下齿轮）
2. 左侧选「第三方插件 / Community plugins」
3. 点「关闭受限模式 / Turn off restricted mode」（首次必须）
4. 点「浏览 / Browse」，依次搜索并安装：
      Templater      → 自动填标题、弹窗选领域
      Dataview       → 按 frontmatter 生成看板
      Tag Wrangler   → 批量改标签，防止词表分裂
5. 回到「已安装插件」列表，确认三个都处于开启状态
```

插件 id（已预写入配置）：`templater-obsidian`、`dataview`、`tag-wrangler`

> ⚠️ **已知兼容性风险**：[Templater 2.21 与 Obsidian 1.12.7+ 存在不兼容报告](https://github.com/SilentVoid13/Templater/issues/1748)，
> 你的 Obsidian 是 **1.13.7**，属于受影响区间。
> **不要**手动下载旧版插件安装——从官方市场装会拿到与你版本匹配的最新版。
> 若装完 Templater 无法启用，**先不管它**，用原生模板继续（已配好），
> 或到插件设置里关掉它的自动更新再等新版。

## 五、git 远端

远程名 `origin`，指向 GitHub 私有库（建议名 `knowledge-base`）。

### 首次配置（一条命令）

```powershell
# 1. 先在 GitHub 网页建【私有】空仓库，不要勾选 README/gitignore/license
# 2. 回到本库根目录执行（把 jjnz 换成你的 GitHub 用户名）
node tools/remote.mjs jjnz
# 3. 推送
git push -u origin main
```

推送凭据用 **Personal Access Token**，不是账号密码：
GitHub → Settings → Developer settings → Personal access tokens → 勾 `repo` 权限。

### 网络说明（2026-09-23 实测）

| 测试 | 结果 |
|---|---|
| TCP `github.com:443` | ✅ 通 |
| TLS 握手（curl / git） | ❌ `schannel: SEC_E_NO_CREDENTIALS` |
| 本机代理端口（10809/7890 等） | ❌ 未监听 |

**Agent 沙箱禁止建立出站 TLS，所以 push 必须由你在自己的终端执行。**
这不是网络故障，先直连试；只有终端直连也失败，才配代理：

```powershell
git config --global http.proxy  http://127.0.0.1:10809
git config --global https.proxy http://127.0.0.1:10809
# 取消代理
git config --global --unset http.proxy
git config --global --unset https.proxy
```
