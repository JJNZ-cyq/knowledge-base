## 二、覆盖率分析：文献池 vs 你的两个重点

**结论：101 篇里只有约 1/3 服务于你的两个重点，而且缺的恰好是"理论地基"。**

存量文献的构成是典型的 **"应用型规划文献库"**——大量选址定容、技术经济评估、路域光伏，
而这两块正是你说"暂缓"的。**如果按现有文献去学，学到的会是规划，不是调度和交通流分配。**

### 2.1 能量调度：缺"运行层"和"时间尺度衔接"

现有 21 篇集中在**日前调度**（6 篇）与**能量管理策略**（8 篇）。缺口：

| 缺失内容 | 为什么必须要 |
|---|---|
| **模型预测控制 / 滚动时域优化（MPC）** | 日前 → 日内 → 实时的衔接靠它；现有文献只有"日前"，没有"修正机制" |
| **储能寿命与衰减建模** | 调度模型里储能成本若按线性算，结论不可信；审稿必问项 |
| **需求响应的用户行为建模与弹性** | 现有文献把负荷当给定的，实际 DR 效果取决于响应函数 |
| **实时控制的通信延迟与鲁棒性** | 从"优化问题"走向"控制系统"的门槛 |
| **多时间尺度耦合的一致性** | 日前决策如何约束日内，本身是独立的方法论问题 |

### 2.2 交通流分配：缺"经典理论"，几乎全是应用 ⚠️ 最严重

现有 13 篇全是路径规划/需求预测/充电诱导的**应用**，
**没有任何一篇讲交通流分配的经典理论**：

| 缺失内容 | 为什么必须要 |
|---|---|
| **Wardrop 用户均衡 / 系统最优原理** | 整个学科的出发点；不做均衡假设，"分配"无从谈起 |
| **Beckmann 变换与等价性证明** | 把均衡转化为凸优化，是所有算法的基础 |
| **Frank-Wolfe 算法** | 求解 UE 的标准算法，必须能自己实现一遍 |
| **变分不等式（VI）框架** | 非对称、多模式、动态分配都靠它统一表述 |
| **动态交通分配（DTA）** | 静态均衡假设"流量恒定"，与充电负荷的时空动态不匹配 |
| **OD 矩阵估计与交通数据** | 分配模型的输入，绕不开 |

> **这意味着**：`02-交通流分配` 子区目前**没有可用的知识地基**。
> 应对方式：把它当作"新知识获取"而非"文献整理"——**先补理论，再看应用**。

### 2.3 优化方法论：从存量文献反推的高频方法

101 篇标题里统计出的方法关键词，可做 `15-优化方法论` 的第一批知识点：

| 方法 | 出现场景 | 建议 |
|---|---|---|
| 双层 / 三层规划 | 充电站规划、主从博弈 | 独立建卡；交能融合里出现频率最高 |
| 分布鲁棒优化（DRO） | 不确定性配置、轨交光伏 | 近三年高频 |
| 随机-鲁棒混合 | 多微网日前优化 | 已有 2 篇直接对应 |
| 多目标优化 + MCDM | 选址、评估 | 大量出现 |
| 博弈论（Nash / Stackelberg） | 充电定价、路径诱导 | 与交通流分配强相关 |
| 强化学习 / 深度 RL | 充电枢纽规划、共享车调度 | 新兴，2025 年文献出现 |

## 三、迁移到 Zotero 的操作步骤

### 3.1 先建 collection 结构

在 Zotero 里建三个 collection，**名字必须与下方完全一致**：

```
01-能量调度      （21 篇）
02-交通流分配    （13 篇）
暂缓            （67 篇）
```

### 3.2 导入流程

1. Zotero → 文件 → 导入 → 选 `E:\文献收集` 整个目录，勾选"复制到 Zotero 存储目录"
2. 导入后**先不移动**，所有条目都在"我的文库"根下
3. 按 `literature/文献分类.tsv` 的分类列，用 Zotero 搜索框搜标题，拖进对应 collection
4. 核对元数据（见 3.3）

### 3.3 元数据核对：这次不必逐篇手查 ✅

**98/101 篇有 DOI**，且已从 CrossRef 拉到权威元数据。
对**有 DOI 的条目**用右键 → "通过标识符添加"重新抓取即可，质量由 CrossRef 保证。

**只有 3 条需要人工处理**：

| 文件 | 情况 | 处理 |
|---|---|---|
| `gurobi.pdf` | **不是论文**，是 Gurobi 求解器手册 | 不要放进文献库；归入 `12-编程与工程/Python/优化建模/` |
| `Optimal-Configuration-of-Self-Consistent-Microgrid-System_2023_IFAC` | CrossRef 无记录（IFAC 会议论文） | 手工填标题/作者/年份 |
| `Hesitant-bipolar-fuzzy-set-based-decision-system_2025` | 有标题无 DOI | 手工填，或按标题搜 DOI |
