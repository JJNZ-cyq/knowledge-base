# ⚡ 能量调度

> `10-交能融合` 的子区，**当前两个重点之一**。
> 核心问题：**什么时候充放多少电。**

## 覆盖范围

| 维度 | 内容 |
|---|---|
| 对象 | 微网 / 光储充站 / 服务区综合能源 / 电氢耦合系统 |
| 时间尺度 | 日前调度 → 日内滚动 → 实时控制 |
| 目标 | 经济性、低碳、寿命、可靠性、弃光率 |
| 手段 | 有序充电、需求响应、储能充放策略、多微网协同 |
| 难点 | 不确定性、多时间尺度耦合、通信延迟、用户行为 |

## 什么放这里 / 什么不放

| 放进 | 放到别处 |
|---|---|
| 日前/日内/实时调度模型、能量管理策略、需求响应机制 | 双层/DRO/随机规划的**方法本身** → `15-优化方法论` |
| V2G 的**功率控制**部分 | 充放电的**容量规划** → `09-其他`（暂缓） |
| 用 Gurobi/Pyomo 实现调度模型 | 那个模型同时是问题卡时 → `30-问题卡` |
