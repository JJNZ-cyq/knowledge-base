# 🤖 大模型

> 顶层领域之一。**目前完全空白**——计划先学完 Python（见 `docs/Python 学习计划.md`）。

## 这个领域在问什么

模型的能力边界在哪、怎么用好它、怎么和自己的领域结合。

## 分区地图

| 分区 | 内容 | 放哪 | 价值 |
|---|---|---|---|
| A. 基础机制 | Transformer、注意力、训练目标、Scaling Law、位置编码 | `知识卡\` | 不易过期，值得记 |
| B. 提示与推理 | 提示工程、CoT、上下文学习、RAG | `知识卡\` | **最实用** |
| C. 微调与对齐 | SFT、LoRA/QLoRA、RLHF/DPO、评测 | `知识卡\` | 不做训练，了解即可 |
| D. 智能体 | 工具调用、多智能体、规划、记忆 | `知识卡\` | 与交能融合有交叉 |
| E. 落地工程 | 部署、量化、推理加速、成本 | `知识卡\` | 用到再看 |
| F. 与领域结合 | LLM 辅助优化建模、文献处理、代码生成 | → `19-交叉\` | **真正机会在这** |

## ⚠️ 这个领域独有的规则（其他领域没有）

**知识半衰期只有 3~6 个月。** 所以：

1. **优先记机制与原理，不记模型名和跑分** —— 原理不易过期，跑分半年就废
2. **每张结论卡必须带两个字段**：

```yaml
claim:        该结论是什么
verified_at:  2026-09-24     # 所有能力性结论必须带日期
may_expire:   true           # 标记易过期结论，复习时优先
```

3. **信息来源与别的领域不同**：以 arXiv、官方技术文档、HuggingFace 为主，
   **期刊文献是次要的**——所以 `文献笔记\` 可能长期用不上。
