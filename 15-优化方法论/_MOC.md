# 📐 优化方法论

> 横切方法论领域。**它不属于任何一个具体方向**——三个领域都要用它。

## 为什么它单独成区

存量 101 篇文献里，双层、多目标、分布鲁棒、MILP 这些方法**反复出现在不同应用场景**，
但知识本身与应用无关。独立成区后：**学一次，处处可用。**

如果把它拆散进各篇文献笔记，就会变成"每篇都在重复学同一个方法"。

## 分区地图

| 分区 | 内容 |
|---|---|
| `建模范式` | LP / MILP / MINLP / 双层 / 多目标 / 随机规划 / 分布鲁棒 / 机会约束 |
| `求解与工具` | Gurobi、CPLEX、对偶与 KKT、线性化技巧、求解器调参 |
| `不确定性` | 场景生成与削减、鲁棒集构造、Wasserstein 球、样本外验证 |

## ⚠️ 本区的双向链接约定（这是它最有价值的地方）

| 方向 | 怎么做 |
|---|---|
| 方法论卡 → 领域卡 | 在 `used_in: []` 字段列出**用到了哪些领域问题** |
| 领域卡（文献笔记）→ 方法论卡 | 在 `method` 字段填方法名，形成反向索引 |

这样"**某个方法我到底在哪些问题上用过**"可以一键查出——
**这是整个库最实用的查询之一。**

## 什么放这里 / 什么不放

| 放进 | 放到别处 |
|---|---|
| 方法本身：定义、适用条件、转化技巧、失效边界 | **用 Gurobi 实现这个方法** → 放这里，加 `#prog` 标签 |
| 求解器调参、数值问题 | **某个具体调度模型** → `10-交能融合/01-能量调度` |
| 不确定性建模的通用手段 | **某个具体应用的不确定性** → 对应领域 |
