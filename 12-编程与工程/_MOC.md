## ⚠️ 这个领域的两条特殊规则

**1. 这里没有"文献卡"。** 知识来源是**代码、文档、踩坑**，不是论文。
所以卡型以**踩坑卡**为主（`symptom` / `cause` / `minimal_repro`）。

**2. C++ 的卡必须附可编译片段。**
C++ 的坑都藏在细节里（生命周期、拷贝次数、UB），纯文字描述必然记错。
片段放 `90-附件/cpp-snippets/<卡名>.cpp`，**必须能编译**。

同时维护 `CPP\坑清单.md`：一行一个"症状 → 原因"，检索价值极高。

## C++ 的启动条件（不急）

满足**任一条**再开始：

- 要写仿真内核，纯 Python 跑不动
- 优化模型规模上来，求解前后的数据处理成为瓶颈
- 需要读某个 C++ 库的源码

> C++ 是**性能语言**，不是入门语言。它解决的问题是"已经能跑，但太慢"。
> 现在没有"太慢的东西"，学了没有着力点。
